# MailBox

淡い水色を標準テーマにした、スマートフォン・PC対応のメールクライアントUIプロトタイプです。

## 起動方法

`index.html` をブラウザで開くか、フォルダ内で簡易HTTPサーバーを起動してください。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 現在動作する機能

- レスポンシブな受信箱UI
- サンプルメールの一覧、検索、スター切り替え
- フォルダ表示、選択メールの既読・アーカイブ・削除操作
- テーマカラーの選択とカスタムカラー
- ライト／ダークモード
- プロフィール画像・背景画像の設定
- アカウント追加UI（接続待ちアカウントとして表示）
- 下書きUI、設定エクスポート
- ブラウザ内の設定保存（localStorage）

## 実メール接続について

このプロジェクトはUIプロトタイプです。Gmail、Microsoft、Yahoo!メールの実データを取得・送信する機能はまだ接続されていません。アカウント追加画面は接続先を登録するUIであり、認証やメール同期は行いません。

実接続にはバックエンドが必要です。OAuthの認可コードフローをサーバー側で実装し、トークンは暗号化してサーバー側に保存してください。ブラウザにクライアントシークレットやリフレッシュトークンを置かないでください。

- Gmail: Google Cloud project、Gmail API、OAuth同意画面・スコープ審査
- Outlook: Microsoft Entraアプリ登録、Microsoft Graph Mail API
- Yahoo! JAPAN: 外部メールソフト設定、IMAP/SMTPの利用条件・認証方式を確認
- その他: IMAP/SMTPサーバー設定と安全な資格情報保管

送信予約、通知、バックアップ、自動返信、メール翻訳、リマインダー、自動振り分けも、実メール接続後にバックエンド機能として実装する必要があります。

## セキュリティ上の注意

このUIプロトタイプに実際のメールパスワードを入力しないでください。サンプル表示・ブラウザ内設定保存のみを行います。画像はブラウザのlocalStorageに保存されるため、大きな画像は避けてください。
